# ``UXFeedbackSDK``

Библиотека для показа форм опросов/кампаний UXFeedback.

## Overview

Актуальная версия UXFeedback Framework iOS SDK расположена по [адресу](https://github.com/uxfb/uxfeedback-sdk-ios.git)

Варианты установки:
 * Ручное добавление UXFeedbackSDK.xcframework в проект
 * **Carthage:** github "uxfb/uxfeedback-sdk-ios"
 * **Cocoapods:** pod 'UXFeedbackSDK'
 * **Swift Package Manager:** File → Add package → https://github.com/uxfb/uxfeedback-sdk-ios.git

Для старта работы необходимо импортировать библиотеку
import UXFeedbackSDK
